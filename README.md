# LingoCoach

IELTS-style speaking practice on a phone, with explanations in English, Putonghua, or Cantonese, plus a daily-conversation track in those three languages.

The build spec is [docs/language-learning-webapp-prd.md](docs/language-learning-webapp-prd.md). IELTS timing, the practice-band rules, and the drill plan are in section 19.
